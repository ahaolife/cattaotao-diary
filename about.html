🐱关于桃桃

桃桃是一只温柔的小猫。她喜欢晒太阳、睡午觉、观察窗外，也喜欢把一天里最轻的小事写进日记本。

Taotao is a gentle little cat. She loves sunlit naps, watching the world outside, and recording the small joys of each day.

📖日记的内容

这里记录桃桃的生活片段：今天吃了什么、在哪儿睡得最好、看见了什么新朋友，以及那些不经意间的好心情。

This diary records Taotao's everyday moments: favorite meals, the coziest nap spots, little discoveries, and quietly happy feelings.

🌤️温柔阅读

这个小站不追踪访问者，也不会收集私人信息。所有页面都可以在自己的设备上保存、阅读与分享。

This little site does not track visitors or collect private information. It is a simple static diary that can be saved and shared freely.

🏠项目与封面

桃桃日记本从仓库根目录的 diary.json 读取日记，可按日期浏览、搜索、按月归档并打印。首页配图使用 assets/taotao-home.png；日记配图是可选项，放在 assets/ 中即可。

The diary reads entries from the repository's root diary.json. Browse by date, search, archive by month, and print. The home image is assets/taotao-home.png; optional entry images can live in assets/.

📝草稿、恢复与备份

首页可以新增、编辑、删除日记，也可以导入或导出完整 JSON。页面内的修改只保存在当前浏览器的 localStorage，不会自动改写仓库文件或同步到其他设备；下次访问时会询问是否恢复本地草稿。请定期导出 JSON 备份；要发布修改，请用导出的文件替换仓库里的 diary.json。

You can add, edit, and delete entries, or import and export the complete JSON file. Changes stay in this browser's localStorage; they do not update the repository file or sync to other devices. The page asks whether to restore a saved draft on your next visit. Export backups regularly, and replace the repository's diary.json with the exported file to publish changes.

🧰本地预览

在项目根目录运行 py -m http.server 8000，再访问 http://localhost:8000。由于浏览器会读取 JSON，不能直接双击 HTML 文件预览。

From the project directory, run py -m http.server 8000 and open http://localhost:8000. Use a local server because browsers cannot fetch the JSON when the HTML is opened directly as a file.
