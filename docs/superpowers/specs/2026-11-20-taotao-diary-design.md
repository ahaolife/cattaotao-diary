# 桃桃日记本改造设计

## 意图与目标

将当前的 AI 学习日记模板改造为“桃桃的日记本”：保留静态 GitHub Pages 部署方式、打字机效果、日期切换、主题切换和响应式布局，把视觉和内容改成温馨可爱的猫咪日记风格。

## 范围

- 首页、关于页和中文项目说明替换为桃桃主题文案。
- 将终端式元素统一为柔和的手帐/猫咪语境，同时保留打字机动效。
- 使用米白、暖粉、浅灰和深灰色系，增加圆角、柔和边框和猫咪装饰。
- 保留现有横图资源 `assets/cover.png`；如用户替换了横图，则直接展示替换后的内容，不再改图。
- 保持纯 HTML/CSS/JavaScript 和 GitHub Pages，无需新增构建工具或后端。

## 方案与取舍

1. **保留终端风格并替换主题**：改动最少，但会与温馨猫咪日记气质冲突。
2. **温馨猫咪手帐风格，保留现有交互结构（已选）**：视觉明显更贴合桃桃，打字机、日期切换和主题切换继续复用。
3. **重做为带后台和存储的应用**：功能更强，但需要新框架、数据库和部署流程，超出当前静态日记定位。

已选方案二。改造只调整表现层和文案，不改变页面结构的基本信息流，也不引入依赖。

## 实现边界

- 保留打字机、日期切换、亮/暗主题和移动端布局。
- 去除 OpenClaw、比巴卜、AI 学习和机器人学习相关品牌与示例内容。
- 示例日记可采用日常生活、睡午觉、吃饭、玩耍、观察和小心情等轻量主题。
- 不制作不存在的猫咪照片；横图只使用仓库中用户已替换的现有资源。
- README 两种语言、About 页面及页面页脚同步更新。
