# 桃桃日记本纯静态完整版设计

## 意图与目标

把当前静态展示页升级为可长期维护的一人日记本：

- 每一天是一篇完整日记。
- 日记按仓库中的结构化数据维护。
- 页面负责展示、翻页、归档和搜索，不依赖账号、数据库或后端。
- 保持 GitHub Pages 可直接部署。
- 不要求人工编辑 HTML 来维护正文。

## 范围

第一期包含：

- 日记数据文件：日期、标题、天气、心情、正文、标签、可选配图。
- 首页按日期读取并展示日记。
- 日期横向滑动，最多同时展示七天。
- 前一篇、后一篇翻页及键盘方向键。
- 月份归档入口。
- 标题、正文、标签和日期搜索。
- 打印当前日记。
- 亮色与暗色主题。
- 响应式桌面和移动端布局。
- 关于页和 README 同步说明维护方式。
- 页面内新增、编辑和删除草稿。
- 草稿与日记修改先保存到浏览器本地存储。
- 导入和导出完整日记 JSON。
- 浏览器草稿恢复提示和备份提醒。
- 页面内编辑器不要求账号、数据库或云端服务。

第一期不包含：

- 云端账号、数据库、登录或多设备实时同步。
- 图片上传和远程图片存储。
- 浏览器外的后台管理。
- 评论、点赞、分享或多人协作。
- 多作者和可视化编辑器。

## 页面结构

- 顶部保留桃桃日记本标题和打字机副标题。
- 顶部配图使用独立的首页主图资源。
- 日期栏位于日记顶部，以旧到新排列并支持横向滑动。
- 主阅读区只显示当前日期的一篇完整日记。
- 日记顶部显示日期、天气和心情。
- 正文支持标题、段落、引用和标签。
- 翻页导航位于正文下方，固定显示第几篇、上一篇、下一篇。
- 月份归档和搜索位于独立区域，不分拆成摘要卡片式首页。

## 数据结构

采用仓库根目录下的 `diary.json`，每篇日记为独立对象：

```json
{
  "date": "2026-11-20",
  "title": "暖暖的午后小憩",
  "weather": "晴",
  "mood": "软软的、暖暖的",
  "content": [
    "第一段正文。",
    "第二段正文。"
  ],
  "noteTitle": "今日小确幸",
  "note": "今日小确幸。",
  "tags": ["晒太阳", "午觉"],
  "image": ""
}
```

约定：

- `date` 是唯一标识，格式为 `YYYY-MM-DD`。
- 日记按日期倒序存储或正序存储均可，页面统一排序。
- `content` 支持纯文本段落，第一期不解析 Markdown。
- `note` 为可选内容；有 `noteTitle` 时以该字段作为小记标题，否则显示“今日小确幸”。
- `noteTitle` 为可选字段，用于保留不同小记标题。
- `tags` 和 `image` 为可选字段。
- 不把图片放进 JSON，图片仍使用 `assets/` 下独立文件。

## 实现方案与取舍

1. **纯静态加 JSON 数据**：维护简单、GitHub Pages 原生支持、无账号和服务器成本；直接维护的数据变更需修改仓库并重新部署。
2. **浏览器本地存储草稿**：无需立即修改仓库即可新增、编辑、删除日记并导入导出完整 JSON；但草稿只在当前浏览器，换设备或清理数据后需要通过备份恢复。
3. **云端数据库或账号系统**：支持多设备实时同步，但引入登录、密钥、费用和部署复杂度，不符合第一期目标。

已选方案一与方案二结合：仓库 `diary.json` 保留为静态展示和正式备份；网页编辑只保存到浏览器 `localStorage`，再次打开时提示是否恢复。导入会替换当前列表并保存为本地草稿，导出会下载完整 JSON；只有将导出的文件替换仓库文件并重新部署，修改才会成为静态站点的正式数据。方案三不在范围内。

## 核心交互

- 页面加载后读取 `diary.json`。
- 不存在或格式错误的数据只影响日记区，不破坏页面头部和主题。
- 页面内新增、编辑和删除只更改当前浏览器中的草稿，不会改写仓库文件。
- 检测到有效本地草稿时询问是否恢复；用户可恢复草稿或忽略并删除草稿。
- 导入会验证 JSON 数组和唯一日期，并替换当前列表；导出下载完整、按日期排序的 JSON。
- 持续提示草稿仅保存在当前浏览器，定期导出备份并替换仓库文件后才会发布。
- 日期栏以旧到新排列，可横向滑动，最多显示七天。
- 最新一篇为默认打开项。
- 当前日期切换时同步更新正文、翻页状态和浏览器地址。
- 搜索匹配标题、正文、天气、心情和标签。
- 月份归档按当前年份和月份分组。
- 前一篇和后一篇按日期排序，不按数组顺序。
- 左右方向键翻页。

## 验证标准

- `diary.json` 中任意一篇日记都能通过日期切换显示完整正文。
- 多篇日记按日期排序，默认显示最新一篇。
- 十篇以上日记时日期栏只显示最多七天窗口。
- 搜索能匹配标题、正文和标签。
- 月份归档能正确筛选对应日期。
- 页面在桌面端和移动端不溢出。
- 无网络数据库依赖，静态服务器即可运行。
- 缺少配图时不显示破损图片。
- 页面内新增、编辑、删除会更新本地草稿；恢复、忽略、导入、导出均有明确反馈。
